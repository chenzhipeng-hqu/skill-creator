# 课程学习与答题

## 确认任务与进度

- 确认课程范围、当前阶段、检查间隔，以及题数、时限、尝试次数和是否计入账号记录。只执行本次用户要求的范围，不继承历史任务的授权。
- 记录进入时的进度和已有选择；除非用户要求或有明确纠错依据，不覆盖已有答案。课程、网址、检查间隔和答案均由当前任务决定，不沿用历史案例。
- 使用当前环境提供的浏览器操作能力；若工具附带使用说明或技能，先读取再操作。不要把此技能当作独立浏览器或后台定时器。

## 学习、监控与恢复

- 阅读课程内容，按约定间隔检查画面、播放状态、剩余时间和页面消息；要求截图时保存实际截图，并记录检查时间和进度。期间发现弹题或暂停时及时处理，不必等下一检查点。
- 出现“继续学习”提示或防挂机验证时，自动识别、处理并确认课程恢复，不逐次请求用户确认。遇到验证码时自行识别、输入并确定；若工具强制拦截或必须本人完成验证，说明具体阻碍，不宣称已经处理。
- 处理后重新读取页面，核对提示消失、播放恢复或计时推进。重复出现同一阻碍且没有进展时，报告当前状态并请求接管，不无限重试。
- 若当前环境无法定时唤醒或持续监控，提前说明能执行的检查范围；中断后从最新页面恢复，不补造遗漏截图或检查记录。页面显示完成不等于已掌握全部课程内容。

## 选择单轮或两轮作答

1. **首题先保守处理。** 尚未确认回退能力，有疑点先查证；在首次离开第1题前保存题目、选项和当前选择。若“下一题”会提交或锁定答案，先按不可回退处理。
2. **首次进入第2题时验证回退。** 检查“上一题”或题目导航是否可用；在不改变答案、不提交的前提下，验证能否返回第1题、已选答案是否保留，以及修改控件是否可用。不要为了测试而改选答案。
3. **可回退且可修改：两轮作答。** 第一轮比较确定的题直接作答，不确定的题立即记下题号、暂选项和疑点，必要时留空；第二轮集中查证这些题并更新选择。交卷前统一保存完整答卷。
4. **不可回退、不可修改或无法确认：单轮作答。** 每题有疑点先查证，并在进入下一题前保存完整单题记录，不等交卷前再回收题目。只有一题时也按单轮处理。

切换题目后重新读取题干和选项，避免沿用上一题的位置或选择。单选确认恰有一项，多选逐项判断并检查漏选；操作后核对实际选中状态和作答进度。

## 查证与单题记录

- 比较确定且直接作答的题不强制附证据；经过核实的题记录来源；有疑点的题必须查证并记录结果。
- 优先使用课程课件、课程资料和平台已展示的判题解析；公司专有术语或制度以对应原文为准，不用常识替代。区分课件直接印证、概念推断和平台判定。
- 找不到证据时标为“未核实”，来源写“未找到”。在进入不可回退的下一题或最终交卷前告知用户；若下一步会锁定未核实答案，等待用户决定，不静默猜测后继续。
- 平台给出反馈时，分开记录已提交选项、平台正确项和解析；反馈仅代表已展示的内容，不反推未展示题目的标准答案。

单题记录使用以下字段，按上述单轮或两轮时机保存：

```text
题号 / 题型：
题干与全部选项：
当前选择：
选择来源：原有选择 / 本次填写 / 本次修正
确认状态：直接作答 / 查证确认 / 推断待核 / 未选择 / 平台已判定
疑点：无 / 具体疑点
证据来源：有核实或疑点时填写；未找到则明示
```

## 复核、提交与交付

- 交卷前核对单选、多选、遗漏题和未核实项，在当前任务输出位置保存带时间与作答状态的答卷快照；单轮题目从逐题记录汇总，不假定仍能返回。
- 说明将提交到哪个平台、对账号记录或尝试次数的影响，以及尚未核实的答案；获得本次明确确认后才执行最终提交。自动处理继续学习提示或防挂机验证不包含交卷授权。
- 提交后读取提交状态、成绩和通过情况；区分助手提交、用户自行提交和用户提供的结果截图。不能仅凭总分证明每题已核验或快照与最终答卷一致。
- 汇报已完成范围、剩余内容、未核实项和实际结果；答卷快照不是标准答案或最终成绩，非必要不记录姓名、账号、部门等个人信息。
