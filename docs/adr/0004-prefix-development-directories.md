# Prefix development directories

Name every repository-root Development Directory `sk-<skill-name>/` while keeping the canonical Skill Name unchanged in `SKILL.md`, `skills/<skill-name>/`, `tests/<skill-name>/`, CLI input, tags, and Agent installations. This deliberate asymmetry makes active development work visually and mechanically distinct in the repository's mixed root namespace without imposing a nonstandard prefix on installed Skills; canonical Skill Names beginning with the reserved `sk-` prefix are invalid so the mapping remains unambiguous.
